# SwipePix 📸

**SwipePix** is a simple and intuitive photo-cleaning app that helps you organize your gallery by swiping through your photos.

Swipe right to keep a photo, swipe left to mark it for deletion, and clean up your gallery with ease.

## ✨ Features

- 👈 **Swipe Left** — Mark a photo for deletion
- 👉 **Swipe Right** — Keep a photo
- ↩️ **Undo** — Undo your last swipe
- 🗑️ **Photo Review** — Review photos selected for deletion
- 📊 **Progress Tracking** — Track your photo-cleaning progress
- 🎨 **Modern UI** — Clean and intuitive interface

## 📥 Downloads

Download the files from the [Releases](../../releases) page.

| File | Platform | Description |
|---|---|---|
| `SwipePix.apk` | Android | Ready-to-install Android application |
| `SwipePix.zip` | iOS | Xcode source project for building and installing SwipePix on your iPhone |

### 🤖 Android

The APK is already built and ready to install.

1. Download `SwipePix.apk` from Releases.
2. Open the APK on your Android device.
3. Allow installation if prompted.
4. Install SwipePix and enjoy!

### 🍎 iPhone / iOS

The ZIP contains the iOS source code, not a prebuilt IPA.

To install SwipePix on your iPhone:

1. Download `SwipePix.zip`.
2. Extract the ZIP file.
3. Open the project in **Xcode** on your Mac.
4. Connect your iPhone to your Mac.
5. Select your iPhone as the build target.
6. Build and run the app on your device.

You need a Mac with Xcode to build and install the iOS version.
